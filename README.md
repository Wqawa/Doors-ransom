# Ransom_dev

**中文** | [English](README.en.md)

把《DOORS》里的 **Ransom（A-90）遭遇战**做成一个真的会动你桌面的 Windows 整蛊程序。

脸在你屏幕上随机浮现 → 你必须停下不动 → 红色停牌闪现的那一瞬判定：没动，它退走；
动了，满屏弹窗糊上来、桌面快捷方式被标成「已加密」、所有开着的程序被收进任务栏，
你必须在 90 秒内凑够 500 Gold 赎回，否则 jumpscare 收场、被锁的快捷方式进回收站。

C++20 + Win32 + GDI+，**素材全部内嵌在 exe 里**，产物就一个文件。

> ⚠️ **先读这段。** 这个程序会真的改你的桌面：移动图标、拦右键、最小化你的窗口、
> 超时还会把快捷方式丢进回收站。所有动作都可逆，退路见 [安全阀与回滚](#安全阀与回滚)。
> **第一次跑之前先看那一节。**

## 环境要求

| 项目 | 要求 |
|---|---|
| 系统 | Windows 10 1809+（用到 `SetProcessDpiAwareness`、分层窗口、低层输入钩子） |
| 编译器 | Visual Studio 2022（v143）。工程里写的是 `v145`，用旧版打开时右键工程 →「重定解决方案目标」 |
| 组件 | 「使用 C++ 的桌面开发」工作负载 + Windows 10 SDK |
| 语言标准 | C++20（工程已设 `/std:c++20`） |
| 运行时 | 不需要。CRT 静态链接（`/MT`），拷走就能跑 |
| 其它 | PowerShell（构建时自动跑素材打包脚本） |

ogg / mp3 解码器是**源码内联**的，已在 `third_party/`，不需要包管理器。

## 构建

```powershell
# Visual Studio：打开 Ransom_dev.sln，选 Release | x64，生成
# 命令行：
msbuild Ransom_dev.sln /p:Configuration=Release /p:Platform=x64 /m
```

产物路径在工程文件里**显式钉死**，不跟解决方案文件跑：

```
build\x64\Release\Ransom_dev.exe     ← 就这一个文件，素材全在里面
build\x64\Release\Ransom_dev.pdb
build\obj\...                        ← 中间文件
```

只有 `x64|Release` 是发布配置；`Win32` 和 `Debug` 也留着方便调试。

### 素材是怎么进去的

构建时 `tools/gen_assets.ps1` 扫描 `assets/`，生成 `Ransom_dev/assets_gen.rc`
（每个素材一条 `RCDATA` + 数字 ID）和 `assets_gen.txt`（名字 → ID 清单）。
`assets.cpp` 启动时读 ID 1000 那份清单建表，之后用 `FindResourceW` 取字节 ——
所以运行时**不依赖 `assets/` 目录**，改素材要重新编译（有意的：单文件产物好处更大）。

> 脚本靠**比内容**而不是比时间戳决定要不要重写这两个文件。新素材完全可能带着旧时间戳
> 进来（`Copy-Item` 和 unzip 都会保留原时间），按时间戳判断会安静地漏掉。

## 跑起来

双击 `Ransom_dev.exe` 就行。它会先弹一个设置界面，确认后才开始演出。

第一次跑建议按这个顺序，先看清楚它会干什么：

```powershell
# 1. 只看画出来的脸，不碰桌面
Ransom_dev.exe --face-demo idle

# 2. 只看勒索窗口的排版（渲染成 PNG 就退出）
Ransom_dev.exe --ui-preview preview.png --ui-grid

# 3. 真要跑整场了 —— 先读下面的「安全阀」
Ransom_dev.exe
```

启动设置界面可以调**赎金目标金币（10–1000，默认 500）**、金币面额、音量、
弹窗间隔、以及**光敏安全模式**（抑制闪烁与噪点）。`--no-setup` 可以跳过它。

## 安全阀与回滚

程序动你桌面的每一处都留了退路：

| 情况 | 怎么退 |
|---|---|
| **任何时候想立刻停** | 按 `Ctrl + Alt + Shift + Q`（全局热键，被判定逻辑豁免，不会误伤） |
| 金币快捷方式没清干净 | `Ransom_dev.exe --clean-gold` |
| 快捷方式被丢进回收站 | `Ransom_dev.exe --restore` |
| 被收走的窗口没还回来 | 正常退出的路径**一定会还原**；被任务管理器强杀不会 —— 那种情况去任务栏点一下 |
| 桌面图标被挪了 | 桌面右键 →「查看」→ 勾「自动排列图标」再取消，图标归位 |

正常退出的路径（付清 / 超时受罚 / 按安全阀 / 关窗口）都会：还原窗口、删掉全部生成的
金币快捷方式、把被没收的快捷方式按清单放回原位。

> 程序还会在**支付时必须带着正确口令**才会认账，所以桌面上随便新建一个同名快捷方式骗不了它。

## 演出流程

```
潜伏 IDLE ──> 脸在随机位置浮现 FACE ──> 瞬移到中央 CENTER（同时闪出停牌）
                                              │
                              停牌显示约 1 秒，这期间「不许动」
                                              │
                              ┌───────────────┴───────────────┐
                         没动 │                               │ 动了
                              ▼                               ▼
                        避开 ESCAPED                     被抓 CAUGHT
                    头再露一下就走人                   jumpscare ──> 加载画面
                                                              │
                                                              ▼
                                                     勒索 RANSOM（90 秒）
                                              · 满屏弹窗 + 桌面图标标「已加密」
                                              · 所有开着的程序被收进任务栏
                                              · 去点桌面上生成的金币快捷方式攒够目标金币
                                                              │
                                              ┌───────────────┴───────────────┐
                                         付清 │                               │ 超时
                                              ▼                               ▼
                                        付清 PAID                       惩罚 PUNISH
                                      致谢画面 + 全部还原            jumpscare + 快捷方式进回收站
```

「动了」的判定很宽：鼠标位移超过容差（默认 20px）、按了键、都会被抓，`--tolerance N` 可放宽。

## 命令行开关

### 调试与自检（都不碰你的桌面，导出完就退出）

| 开关 | 作用 |
|---|---|
| `--phase NAME\|N` | 直接跳到某个阶段并停住。名字：`潜伏` / `任意位置浮现` / `瞬移到中央` / `停牌判定` / `避开` / `被抓` / `付清` / `惩罚`，或序号 0-7 |
| `--no-auto` | 不自动推进阶段（配 `--phase` 用，方便慢慢看某一帧） |
| `--face-demo MODE` | 只显示某一张脸：`idle` / `stop` / `attack` / `thanks` / `loading` |
| `--face-dump DIR` | 把程序生成的脸导出成 PNG 后退出 |
| `--ui-preview PATH` | 把勒索主窗口排版渲染成 PNG 后退出（调排版用，不用跑整场） |
| `--ui-grid` | 配合 `--ui-preview`，预览图叠坐标网格 |
| `--payup` | 配合 `--ui-preview`，预览付钱那一屏 |
| `--setup-ui PATH` | 把**启动设置界面**渲染成 PNG 后退出 |
| `--setup-grid` | 配合 `--setup-ui`，叠坐标网格 |
| `--notice-ui PATH` | 把**告知/提示界面**渲染成 PNG 后退出 |
| `--fx-demo NAME` | 选特效层的效果：`glow`（四角红光）/ `black`（黑幕+噪点）/ `stop`（红屏） |
| `--fx-dump PATH` | **和 `--fx-demo` 是两个独立开关**：前者选效果，后者给导出路径。两个都要给才会出图 |
| `--audio-dump PATH` | 把全部音效离线渲染成 WAV 后退出（验波形用） |
| `--theme-dump PATH` | 把处理后的主题曲导成 WAV 后退出（试听用） |
| `--diag PATH` | 把诊断日志写到文件。GUI 子系统没有控制台，排查全靠这个 |

### 演出开关

| 开关 | 作用 |
|---|---|
| `--tolerance N` | 鼠标容差像素，默认 20 |
| `--no-setup` | 跳过启动设置界面，直接进入演出 |
| `--no-audio` | 不启动声音 |
| `--no-overlay` | 不启动桌面覆盖层（不画方框、不拦点击） |
| `--overlay-topmost` | 覆盖层置顶（默认贴桌面层，会被普通窗口盖住） |
| `--no-block-menu` | 不拦被加密图标上的右键菜单（**排查问题时用**） |
| `--no-lockdown` | 勒索时不最小化别的程序（**排查问题时用**） |
| `--no-guardian` | 不启动守护进程（**排查问题时用**，见下方说明） |
| `--image-dir DIR` / `--audio-dir DIR` | 覆盖素材目录（默认从 exe 内嵌资源里取） |

### 急救与内部开关

| 开关 | 作用 |
|---|---|
| `--clean-gold` | 只扫描并删除遗留的金币快捷方式，然后退出 |
| `--restore` | 按清单把被没收的快捷方式从回收站还原，然后退出 |
| `--pay N --token T` | 向**正在运行**的那一场演出投递支付指令（`N`=金币数）。需要一个带 `RansomDevIpcWnd` 窗口的实例在跑 |
| `--guardian PID GEN` | 守护进程模式，由主程序自己拉起，**一般不需要手动用** |

> **守护进程是什么**：演出开始后主程序会另起一个自己的副本守着。如果你在任务管理器里
> 把主进程杀掉，守护进程会立刻判定为「玩家作弊」，直接触发攻击。`--no-guardian` 关掉这个行为。

## 几个实现上的取舍（为什么这么写）

**排版不写死在代码里。** 勒索主窗口的位置、尺寸、颜色全在 `assets/main_window.ini`，
改排版不用重编译；配 `--ui-preview` 直接把排版渲染成 PNG，还能叠网格读坐标。

**改桌面必须在系统最底层做。** 「图标拖不走」「右键弹不出菜单」都是拿 `WH_MOUSE_LL`
低层钩子吞消息实现的。有个反直觉的点：**拖动必须拦在「按下」，不能拦在「抬起」**——
拖放循环是本进程 UI 线程在跑，超过系统给钩子的超时（约 1 秒）钩子会被**静默摘掉**，
拦在抬起的话「拖慢一点」就能绕过去。低层钩子被摘掉本身很难缠，所以覆盖层的定时器
每跳一次都会重挂一遍钩子兜底。

**判定用的矩形和绘制的矩形是两套。** 覆盖层画出来的方框带逐帧随机抖动（看起来像图标
在躁动），但命中判定用不带抖动的那套 —— 否则图标一抖判定区就漂走，明明点在图标上却漏判。

**清场要防「打地鼠」。** 最小化所有窗口后，有几个 UWP 窗口会自己弹回来。守望如果无脑
压回去，会变成每 150ms 一次的徒劳死循环（实测一场戏累计 1159 次）。所以加了「认输」
逻辑：同一个窗口试 6 次还收不住就放弃它，并把名字写进日志。

**支付要验口令。** 主程序把自己暴露成一个消息窗口，收钱时校验口令，避免桌面上随便
建个同名快捷方式就把赎金「付」了。

## 已知限制

- **横向**：只做了 x64 发布配置。Win32 能编译，没测过。
- **多显示器**：脸的位置和弹窗分布按主屏算，副屏上没有演出。
- **任务栏**：点任务栏按钮仍可能把被清场的窗口拉起来**闪一下** —— 那一下是发给 explorer
  的普通鼠标消息，不在键盘钩子的管辖范围。要彻底堵死得装 `WH_SHELL` 钩子。
- **UWP 窗口**：见上面「打地鼠」，少数 UWP 应用收不住。
- **强杀不还原**：任务管理器强杀进程的话，被收走的窗口和金币快捷方式会留下，
  用 `--clean-gold` 清理。
- **explorer 重启**：覆盖层会重新找桌面窗口，但桌面图标位置会丢一帧。
